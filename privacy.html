1. Introduction

Welcome to Nirma Smart Attendance, an open-source browser extension developed by Shrey113 to help Nirma University students effortlessly evaluate course attendance, calculate safe bunks, and run what-if leave simulations.

We believe in strict, uncompromising privacy. This Privacy Policy details how the extension accesses, processes, and stores information when you use it with the Nirma University Management Information System (MIS) portal.

Key Guarantee: Zero External Telemetry All attendance parsing, safe leave mathematical calculations, and scenario simulations happen entirely within your local browser runtime. No data is ever sent to any external server or third party.

2. Information Accessed and Processed

When you log in to the Nirma University MIS portal and open your Student Attendance Report (https://mis.nirmauni.ac.in/Reports/StudentAttendanceReport.aspx), the extension reads only the rendered attendance table DOM elements on that page:

  • Course Details: Course Code, Course Title, and Load Type (Lecture vs. Practical / Lab).
  • Session Counts: Number of present sessions, absent sessions, and total sessions conducted to date.
  • Attendance Percentages: The official percentage reported by the university portal.

Information We Do NOT Access: The extension does not read, intercept, or log passwords, authentication tokens, financial records, grade histories, or personal identifiable information (PII) beyond what is displayed in the active attendance report table.

3. Data Collection and Transmission

Based on verified inspection of the extension's source code:

  • Zero Remote Servers: The developer does not operate any backend server, database, or API endpoint for this extension.
  • No Outgoing Network Calls: The extension makes no fetch(), XMLHttpRequest, or WebSocket connections to any external domain.
  • No Analytics or Crash Reporting: We do not integrate Google Analytics, Sentry, Mixpanel, Firebase, or any tracking SDKs.

4. Local Data Storage

The extension uses Google Chrome's sandboxed local storage (chrome.storage.local) strictly on your personal device:

Storage Key Purpose Location
nsa_target_percentage Stores your chosen attendance threshold (e.g. 75%, 80%, 85%, or 90%). Local device only
nsa_attendance_cache Caches the parsed course records so you can view attendance offline in the dashboard. Local device only
nsa_last_updated Timestamp of when attendance was last refreshed from the portal. Local device only

This cached data remains exclusively inside your browser profile and is never synced across Google accounts or transmitted outside your computer.

5. How Data is Used

The accessed attendance information is used exclusively to provide the extension's user-facing student utility features:

  • Safe Leave Computation: Determining how many upcoming lectures or practicals can be safely missed without dropping below your threshold ($Target\%$).
  • Catch-Up Calculation: Calculating the exact number of consecutive classes required to restore attendance when currently below target.
  • What-If Scenario Simulation: Computing projected percentage outcomes when taking 1, 2, 3, or more future leaves or attending extra sessions.
  • User Interfaces: Presenting results via the toolbar popup, the in-page floating menu, the single-course deep-dive drawer, and the full dashboard.

6. Data Sharing and Third Parties

We do not share, sell, rent, monetize, or disclose your data to anyone.

There are no third-party advertising networks, analytics partners, data brokers, or hosting providers connected to this extension. Your attendance records are your private academic data.

7. Chrome Permissions Explained

In accordance with Chrome Web Store Minimum Permissions policies, the extension requests only the permissions strictly necessary to execute its advertised features:

Permission Technical Need
storage Used to save your target percentage preference (75%–90%) and cache attendance locally for offline viewing.
activeTab Allows the extension to read the attendance report table when you open the popup on the MIS website.
scripting Enables the injection of table auto-expansion helpers and the deep-dive slide-out drawer on the portal.
https://mis.nirmauni.ac.in/* Restricts content script execution strictly to the official Nirma University MIS portal domain. The extension cannot access any other website.

8. Data Security

Because all data processing occurs within your browser's isolated extension sandbox:

  • Data in transit does not exist; records never travel over the public internet.
  • Data at rest is secured by your operating system and Chrome's profile-level sandboxing.
  • The extension enforces Content Security Policy (CSP) compliant with Chrome Manifest V3, prohibiting remote code execution or inline evaluation.

9. User Rights and Data Deletion

You have full and direct control over all data stored by the extension:

  • Clearing Cached Attendance: You can clear cached data at any time by right-clicking the extension icon in Chrome → Options → Clear Data, or via Chrome's Clear Browsing Data settings.
  • Uninstalling: Removing the extension from Chrome (chrome://extensions) immediately and permanently deletes all local storage and preferences associated with Nirma Smart Attendance.
